# Proiect Final: Site Prezentare - Cafeneaua Boema

Acesta este proiectul final realizat de echipa noastră pentru materia [Numele Materiei, ex: Dezvoltare Web]. Proiectul constă într-un site web complet, receptiv (responsive) și interactiv, dedicat unei cafenele de specialitate fictive numită "Boema".



## 1. Tematica site-ului
Site-ul are ca scop prezentarea imaginii, produselor și poveștii **Cafenelei Boema**.
Conceptul vizual este unul modern, premium și minimalist, axat pe confort și calitatea cafelei de specialitate. Paleta de culori utilizată reflectă această tematică, folosind tonuri de **bej (crem)** pentru fundal, **maro (cafea)** pentru accente, logo și butoane, și **alb** pentru curățenie vizuală.

**Obiectivele site-ului:**
* Atragerea clienților prin imagini de înaltă calitate și o estetică îngrijită.
* Prezentarea clară a meniului (băuturi și patiserie).
* Facilitarea contactului prin intermediul unui formular integrat.
* Oferirea unei experiențe de navigare impecabile pe orice dispozitiv (desktop, tabletă, telefon).

## 2. Platformele și Tehnologiile utilizate
Proiectul a fost dezvoltat "de la zero" (custom made), fără utilizarea unor platforme de tip CMS (WordPress, Wix). S-au folosit tehnologii standard de frontend:

* **HTML5:** Pentru structurarea semantică a conținutului paginilor.
* **CSS3:** Pentru stilizare, layout (Flexbox și CSS Grid pentru grila de meniu), receptivitate (Media Queries) și animații.
    * S-a pus accent pe un design modern cu umbre fine (`box-shadow`) și efecte la trecerea mouse-ului (`hover`).
* **JavaScript (Vanilla):** Pentru interactivitatea site-ului, în special pentru gestionarea meniului de navigare pe dispozitivele mobile (hamburger menu animat).
* **Git/GitHub:** Pentru versionarea codului și colaborarea în echipă.
* **Visual Studio Code:** IDE-ul principal folosit pentru scrierea codului.

## 3. Sursele/modelele de inspirație
Design-ul și experiența utilizatorului au fost inspirate din:
* **Trenduri actuale de UI/UX** pentru site-uri de restaurante și cafenele de tip "Specialty Coffee".
* **Platforme precum Pinterest și Dribbble** pentru definirea paletei de culori și a tipografiei.
* **Modelul paharelor "to-go"** de la branduri globale (ex: Starbucks) pentru vizualul produselor din meniu.

## 4. Materiale bibliografice
Pentru implementarea tehnică și resursele vizuale am documentat și utilizat:
* **Documentație Tehnică:** MDN Web Docs (pentru JavaScript DOM manipulation) și W3Schools (pentru referințe CSS Grid și Flexbox).
* **Tipografie:** Google Fonts - s-au folosit fonturile *Playfair Display* (pentru titluri elegante) și *Roboto* / *Montserrat* (pentru text text de bază și formulare clare).
* **Resurse Vizuale:** Imagini premium generate cu ajutorul **Generative AI** (bazate pe paleta de culori a site-ului) pentru o consistență vizuală totală a brandului (fațadă, logo "B", produse branding "Boema").
